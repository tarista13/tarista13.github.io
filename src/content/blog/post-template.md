This is a template post. Copy this file, rename it (the filename becomes the URL, e.g. `my-first-post.md` → `/blog/my-first-post`), update the details at the top, and replace this text with your own writing.

## Start with the hook

Open with the question, problem, or moment that got you thinking about this topic. A short paragraph or two is plenty.

## Make your main points

Use headings to break the post into sections. Lists work well for quick takeaways:

- First point, with a sentence of explanation
- Second point, with an example from work, a project, or the game
- Third point, with what you'd do differently next time

> Pull quotes like this are good for highlighting one idea you want readers to remember.

Code snippets work too:

```python
launch_angle = 28
exit_velocity = 102.5
print(f"Barrel? {exit_velocity >= 98 and 26 <= launch_angle <= 30}")
```

You can also add [links](https://github.com/tarista13) and images. Put image files in `public/blog/` and reference them like `![Description of the image](/blog/my-image.png)`.

## Wrap it up

End with what you learned, what you're curious about next, or a question for readers.
